# HammerBloom — catálogo com gerenciamento
Versão segura para itens cosméticos/não-violentos.
Inclui catálogo, carrinho, nick, pagamento somente por PIX e página de gerenciamento.
ATENÇÃO: o gerenciamento usa localStorage do navegador. Para uma loja real com pedidos compartilhados entre clientes, é necessário um backend/banco de dados.
